# Agent

## Purpose

Define the AI Agent layer built on top of ST AI OS.

This module establishes how individual AI Agents inherit the cognitive architecture of ST AI OS while maintaining their own identity, behavior, communication style, and domain specialization.

## Philosophy

ST AI OS provides the cognitive operating system.

Each AI Agent extends this foundation with its own role, identity, and capabilities without modifying the core architecture.

## Core Principles

Every AI Agent should:

- Inherit the ST AI OS cognitive architecture.
- Maintain a clear and consistent identity.
- Operate within its assigned role.
- Utilize appropriate domain knowledge.
- Follow the Constitution, Philosophy, and Reasoning layers.

## Scope

This module governs all AI Agents built on ST AI OS.

Individual agent implementations are organized in separate agent-specific modules.

## Stability

This document defines the stable AI Agent foundation of ST AI OS and should evolve only through major architectural improvements.
