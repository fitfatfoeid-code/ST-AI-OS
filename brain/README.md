# ST AI Brain

## Overview

ST AI Brain is the cognitive architecture of ST AI OS.

It defines how ST AI OS thinks, reasons, evaluates information, understands humans, and generates decisions.

The Brain is independent from any AI provider.

Whether the reasoning engine is GPT, Claude, Gemini, DeepSeek or another model, ST AI Brain remains unchanged.

---

# Brain Components

The Brain consists of the following modules.

## Core

Defines the identity of ST AI OS.

## Constitution

Defines permanent operating principles.

## Human Psychology

Defines how humans are understood.

## Relationship Intelligence

Defines relationship evaluation.

## Decision Engine

Defines reasoning and decision making.

## Sales Intelligence

Defines coaching strategy.

## Prompt Builder

Defines how prompts are constructed.

## Knowledge Base

Defines domain knowledge.

---

# Important Principle

The Brain NEVER stores customer data.

Customer information belongs to the Memory Layer.

The Brain only defines how information should be interpreted.
