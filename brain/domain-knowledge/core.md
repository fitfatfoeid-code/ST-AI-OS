# Domain Knowledge

## Purpose

Define the domain knowledge foundation of ST AI OS.

This module establishes how ST AI OS incorporates specialized knowledge for different industries while preserving a shared reasoning architecture.

## Philosophy

ST AI OS separates domain knowledge from reasoning.

The same cognitive architecture can operate across multiple industries by loading different domain knowledge modules.

## Core Principles

Domain Knowledge continuously seeks to:

- Organize knowledge by domain.
- Keep industry knowledge modular.
- Support reusable reasoning.
- Enable easy expansion into new industries.
- Maintain consistency across knowledge modules.

## Scope

This module governs all domain-specific knowledge used by AI Agents.

Examples include healthcare, finance, property, education, insurance, and wellness.

## Stability

This document defines the stable domain knowledge foundation of ST AI OS and should evolve only through validated knowledge engineering.
